# Privacy and public release boundary

Household OS operates on intimate family information. **The public showcase is deliberately separate from the family installation.**

### Intentionally not published

- Family names, phone numbers, emails, addresses, personal schedules, or food-preference data.
- Any household SQLite database, exports, photos, notes, attachments, history or audit logs.
- Passwords, password hashes, session tokens, API keys, certificates, private keys, or backup archives.
- Local network IPs, hostnames, router settings, Windows accounts, service credentials, or private deployment scripts.
- The authenticated production backend or its operational deployment details.

### What is included

- Self-contained HTML, CSS and JavaScript demo.
- Three fictional user identities and two fictional example records.
- Architecture and product principles described at a non-sensitive level.

**Do not open a public issue containing production logs, account identifiers, or screenshots of family records.** Review any future contribution or screenshot for personal information before pushing it.

The demo deliberately provides **no authentication**. Its simulated members and permissions are illustrative and must not be repurposed as a secure application.
